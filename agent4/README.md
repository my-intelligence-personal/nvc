# Yume Landing Page

A beautiful, modern landing page for Yume - an AI-powered e-ink storytelling device that helps children fall asleep naturally with personalized bedtime stories.

## Features

- Responsive design that works on all devices
- Modern UI with smooth animations
- Clear problem/solution presentation
- Interactive waitlist form
- Smooth scrolling navigation

## Getting Started

Simply open `index.html` in your web browser to view the landing page.

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `script.js` - Interactive features and animations

## Product Overview

Yume (夢 - "dreams" in Japanese) is a physical e-ink device that:
- Creates AI-generated visual bedtime stories
- Uses e-ink technology (no blue light)
- Allows interactive story choices via three buttons
- Generates personalized endings for peaceful sleep
